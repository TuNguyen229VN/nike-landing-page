# Nike Landing Page

## Overview

- This is a Nike landing page project built using ReactJS and Tailwind CSS. The main focus of this project is to practice and enhance skills in ReactJS component structure, state management, and responsive design using Tailwind CSS. The page showcases a modern, clean layout typical of a commercial landing page.

**🗓️ Project created on:** May 07, 2022

## Technologies & Libraries:
- **ReactJS**
- **TailwindCSS**
